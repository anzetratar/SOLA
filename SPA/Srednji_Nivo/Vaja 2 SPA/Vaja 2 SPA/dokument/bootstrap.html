Bootstrap

Pregled sodobnega ogrodja za odzivno postavitev, komponente in hitro gradnjo uporabniških vmesnikov.

Kaj je Bootstrap?

Bootstrap je zbirka CSS in JavaScript rešitev za izdelavo odzivnih spletišč. Ponuja mrežni sistem, pripravljene komponente, utility razrede in dosledno osnovo za oblikovanje navigacije, obrazcev, kartic, opozoril, gumbov in drugih delov vmesnika.

Pri učenju je posebej uporaben, ker pokaže, kako z nekaj premišljeno izbranimi razredi hitro zgradimo pregleden in prilagodljiv vmesnik za telefone, tablice in večje zaslone.

Namestitev

Bootstrap lahko dodaš prek CDN povezave, z upravljalnikom paketov ali s prenosom prevedenih datotek. Za večino učnih primerov je najhitrejši začetek uporaba povezave do CSS in JavaScript bundle datoteke.

npm install bootstrap

CDN in bundle

Novejše različice ne potrebujejo jQuery. Za interaktivne komponente praviloma zadošča vključitev datoteke bootstrap.bundle.min.js, ki vsebuje tudi Popper za menije, tooltip in podobne elemente.

To poenostavi odvisnosti in posodobi projekt na sodobnejši način dela.

Predloge in komponente

Ogrodje ponuja veliko primerov postavitve: navigacije, hero odseke, obrazce, kartice, galerije in administrativne vmesnike. Glavna prednost je, da lahko enotno oblikuješ celotno spletišče ter ga kasneje brez večjih težav razširiš.
